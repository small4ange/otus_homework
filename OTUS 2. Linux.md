Подключение по SSH-туннелю на Linux:

Аутентификация SSH:
- приватный ключ - должен храниться только на хостовом компьютере и никогда не передаваться и не копироваться на другие машины. Его ни в коем случае нельзя никому показывать. В PuTTY этот файл имеет расширение `.ppk`
- публичный ключ - Его можно свободно копировать и размещать на всех серверах, к которым вы хотите подключаться.
Когда вы пытаетесь подключиться к серверу, он "проверяет" ваш приватный ключ с помощью сохранённого публичного. Если они подходят друг к другу, доступ разрешается без ввода пароля
**Опции конфигурации SSH в файле /etc/ssh/ssh_config
- PermitRootLogin - определяет возможно ли зайти через пользователя root. Но для безопасности его обычно отключают
- PasswordAuthentication - определяет разрешена ли аутентификация по паролю SSH-ключей
- PubKeyAuthorization - позволяет использовать публичный ключ для подключения
- MaxAuthTries - макс кол-во подключений
- AllowUsers - юзеры которым разрешено подключение

## Общение по netcat

![[Pasted image 20260724112752.png]]

Так можно общаться с другим сервером через файл
Объяснение прослушки:
```
nc - netcat - программа для прослушивания
-l - режим прослушивания - открывает соединение
-p 1234 - на порту 1234
> out.file - все что она будет получать будет записываться в out.file
```
 Объяснение отправки:
 ```
 nc - netcat - программа для прослушивания
 -w 3 - в режиме отправки (записи)
 212.67.14.86 - по такому адресу (destination - IP адрес компа куда будем писать)
 1234 - по такому порту
 < file.file - отправить такой-то файл с локальной машины
 ```
В итоге по 1234 порту мы передали файл с локалки file.file в удаленную машину с IP 212.67.14.86 и там этот файл записался в файл out.file
Так по сути можно тоже между машинами файлики перекидывать как сообщения. Передача файлов через netcat основана на транспортных сетевых протоколах **TCP** или **UDP**, без использования дополнительных протоколов прикладного уровня (таких как FTP или HTTP). Утилита передает чистый поток байтов напрямую через сокеты.

## Задачки на bash скрипты
### 1. 
Задача написать скрипт принимающий 1 число и умножая его на 2 с валидацией входных параметров:
```
if [ -z "$1" ]; then
	echo "Ошибка: Нужно число в качестве аргумента"
	exit 1
fi

if ! [[ "$1" =~^-?[0-9]+(\.[0-9]+)?$ ]]; then
	echo "Ошибка: Введите корректное число."
	exit 1
fi

result=$(echo "$1 * 2" | bc)
echo "Результат умножения на 2: $result"
```
- -z = флаг zero проверка на пустоту
- -n = nonzero проверка на непустоту
- `[[ ... ]]` — расширенная условная конструкция в Bash, которая безопаснее и мощнее старого аналога `[ ... ]`.
- `-n "$1"` — проверка на то, что первый аргумент (`$1`) **не пустой** (его длина больше нуля).
- `&&` — логический оператор «И». Условие дальше выполнится, только если первая проверка прошла успешно.
- `=~` — оператор проверки строки на соответствие **регулярному выражению**.
- `^` — начало строки.
- `-?` — знак минус (`-`) может встречаться один раз или отсутствовать (для отрицательных чисел).
- `[0-9]+` — цифры от `0` до `9`, повторяющиеся один или более раз.
- `$` — конец строки.
- bc - binary calculator мы в него вводим арифметическое выражение, он отдает ответ
